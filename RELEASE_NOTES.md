# Maxweb 1.2.4

- Колокольчик в боковой панели отключает системные уведомления отдельного аккаунта, включая звук баннеров.
- Доступен в развёрнутом и свёрнутом виде, сохраняет выбор после перезапуска и закрывает уже показанные баннеры аккаунта.

## Maxweb 1.2.3

- В настройках внешнего вида добавлен масштаб внутреннего MAX в процентах: от 50 до 200% и кнопка сброса к 100%.
- Масштаб применяется ко всем аккаунтам без перезагрузки, сохраняется при перезапуске и повторной загрузке MAX.
- Команды ⌘+, ⌘− и ⌘0 меняют только содержимое MAX и синхронизируются с полем в настройках.
- Панель аккаунтов и настройки приложения сохраняют масштаб 100%.

## Maxweb 1.2.2

- Переработана шапка боковой панели: компактный знак и название в одной строке с кнопкой сворачивания.
- В свёрнутой панели убран отдельный логотип, оставлена кнопка раскрытия с векторной иконкой и понятным направлением стрелки.
- Уменьшены отступы сверху, элементы выровнены по центру иконок аккаунтов.
- Исправлен размер подписи «Добавить аккаунт» в развёрнутой панели.

## Maxweb 1.2.1

- Боковая панель, настройки, экран блокировки и страница ошибки сети поддерживают светлую и тёмную темы.
- По умолчанию оформление следует теме macOS и меняется сразу при её переключении.
- В настройках появился выбор «Как в macOS», «Светлая», «Тёмная». Ручной выбор сохраняется после перезапуска.
- Переключение оформления не перезагружает аккаунты MAX.

## Maxweb 1.2.0

- Источник обновлений перенесён в effermount/Maxweb; сохранённый адрес прежнего репозитория заменяется автоматически.

- Новая геометрическая иконка M для приложения и строки меню.
- Боковая панель сворачивается до иконок аккаунтов и запоминает состояние (⌘⇧S).
- Название собственного профиля MAX подставляется автоматически; локальное редактирование и возврат к имени MAX доступны через карандаш.
- Уведомления страницы MAX проходят через нативный мост: настройки аккаунта, отправителя/чата, текста и звука, пример баннера и переход в нужный аккаунт.
- PIN 4–8 цифр, Touch ID на поддерживаемых Mac, ручная блокировка ⌘L, автоблокировка по бездействию, при сне и блокировке экрана.
- При блокировке скрываются аккаунты, настройки и личные данные в баннерах; клик по уведомлению открывает чат после разблокировки.
- Проверочная запись PIN защищена scrypt и Keychain, повторные ошибки ограничены задержкой.

## Maxweb 1.1.1

- Исправлена загрузка описаний выпусков через перенаправления GitHub Releases. Используется отдельный HTTP-стек без cookies MAX.
- Сохранены все функции версии 1.1.0: несколько аккаунтов, авторизации, фоновые уведомления и прокрутка к отправленному сообщению.

## Maxweb 1.1.0

- Несколько аккаунтов MAX в одном окне: боковая панель, названия аккаунтов и быстрые клавиши ⌘1–9.
- Изолированные авторизации. Вход основного аккаунта из версии 1.0 сохраняется автоматически.
- Неактивные аккаунты продолжают работать в фоне. Клик по уведомлению открывает соответствующий аккаунт.
- Счётчики непрочитанных сообщений для отдельных аккаунтов и общий счётчик в Dock.
- После отправки сообщения переписка автоматически прокручивается вниз. Входящие сообщения не мешают чтению истории; прокрутка вручную отменяет следование за отправленным сообщением.
- Обновления внутри приложения через публичные GitHub Releases: проверка, скачивание, проверка подписи и установка с перезапуском.
- Подписанные описания выпусков Ed25519 и проверка SHA-256 загруженного файла. При ошибке проверки приложение не заменяется.
