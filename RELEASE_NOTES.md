# Обла 1.2.14

- Maxweb переименован в «Обла»: новое название в интерфейсе, настройках, меню macOS, уведомлениях и на экране блокировки.
- Новая иконка с открытым контуром облака и намёком на диалог. Сохранена фиолетовая палитра; знак используется в приложении и строке меню macOS.
- Единый установщик для Intel и Apple Silicon.
- Прежние данные аккаунтов, идентификатор приложения и совместимость обновлений сохранены. Повторный вход из-за переименования не нужен.
- Доработаны повторная загрузка аватарок Telegram, обновление фото WhatsApp и резервная загрузка изображений при ограничениях веб-страницы; временные ошибки сохраняют прежнее фото.
- Перетаскивание аккаунтов работает в обеих ширинах панели. Убрана дублирующая подпись об отключённых уведомлениях, кнопка блокировки называется «Экран блокировки».

## Maxweb 1.2.13

- Единая Universal-сборка для Mac с Intel и Apple Silicon, macOS 13 и новее.
- Обновления проверяют совместимость архитектуры; сохранён переход со старых ARM64-версий на Universal без выхода из аккаунтов.
- Перетаскивание аккаунтов переведено на обработку указателя: работает в раскрытой и свёрнутой панели, поддерживает отмену через Escape.
- Убрана повторяющаяся подпись об отключённых уведомлениях; состояние отображается колокольчиком, под именем указан мессенджер.
- Кнопка блокировки переименована в «Экран блокировки».
- Доработана загрузка аватарок: повторный запрос в Telegram, обновление неполного кэша WhatsApp и резервная загрузка изображений MAX, WhatsApp и VK при ограничениях веб-страницы. Временная ошибка не стирает сохранённое фото.

Проверка настоящего входа и аватарок в мессенджерах на Intel Mac требует отдельного устройства; локальные проверки выполняются с тестовыми страницами.

## Maxweb 1.2.12

- Порядок аккаунтов можно менять перетаскиванием или Alt+↑ / Alt+↓; он сохраняется после перезапуска. Сочетания ⌘1–9 следуют новому порядку.
- В раскрытой панели имена используют доступную ширину и переносятся без многоточия. Значки встроены в аватар, редактирование расположено напротив имени.
- Убрана подпись «Аккаунты работают в фоне».
- Добавлен VK Мессенджер в выбор аккаунтов с отдельной сохранённой сессией.
- Поддержаны переходы и окно входа VK ID в сессии выбранного аккаунта. Окно входа закрывается при блокировке и выходе; ввод в нём сбрасывает таймер бездействия.
- VK подключён к уведомлениям, отключению баннеров по аккаунту, общему масштабу, блокировке и выходу.
- Имя и фото своего профиля могут подтягиваться из доступного элемента интерфейса VK; ручное переименование остаётся доступным.

Ограничение проверки VK: локальные тесты пройдены, но настоящий вход, получение сообщений и имя/фото после входа ещё требуют проверки пользователем. При онлайн-проверке из текущей сети наблюдались обрывы HTTPS-соединений с VK.

## Maxweb 1.2.10

- Добавлен WhatsApp Web: выбор мессенджера при добавлении аккаунта, отдельные сохранённые сессии, имя и аватар своего профиля, переименование и выход.
- WhatsApp подключён к нативным уведомлениям, отключению баннеров по аккаунту, общей блокировке кодом / Touch ID и масштабу содержимого.
- Аватары в свёрнутой панели увеличены до 44 px, инициалы размещены по центру. Колокольчик и значок мессенджера встроены в нижние углы аватара.
- Фоновая заливка активного профиля заменена аккуратной рамкой и индикатором слева. Цвет профиля сохраняется.

## Maxweb 1.2.9

- В свёрнутой панели восстановлены прежние размер аватаров и компактные отступы.
- Кнопка уведомлений размещена слева снизу, а значок MAX / Telegram — справа снизу. Счётчик непрочитанных остаётся сверху.

## Maxweb 1.2.8

- Значок MAX / Telegram перенесён вправо от аватара в боковой панели.
- В свёрнутой панели значок мессенджера, кнопка уведомлений и счётчик непрочитанных больше не накладываются друг на друга.

## Maxweb 1.2.7

- Поддержка Telegram Web K: при добавлении аккаунта доступен выбор MAX / Telegram. Каждый аккаунт использует отдельную сохранённую сессию.
- Для Telegram добавлены имя и аватар своего профиля, переименование, нативные уведомления с переходом в аккаунт, отключение баннеров и выход из аккаунта.
- Общая блокировка кодом / Touch ID защищает оба мессенджера. Масштаб содержимого применяется к MAX и Telegram; боковая панель сохраняет свой размер.
- В боковой панели отображается тип мессенджера. Существующие сессии MAX сохраняются.
- Исправлена прокрутка MAX после отправки: своё сообщение поднимается выше плавающего поля ввода. Переход к реакции больше не принимается за переход в конец истории; ручная прокрутка отменяет автоматическое доведение.

## Maxweb 1.2.6

- Выход из аккаунта через его настройки: после подтверждения очищается локальная сессия на этом Mac и удаляется значок из боковой панели. Другие аккаунты сохраняются.
- Добавление сразу открывает вход в MAX, без запроса названия. Имя и аватар подтягиваются из профиля; переименование доступно после добавления.
- После выхода из последнего аккаунта список остаётся пустым, в том числе после перезапуска. Новый аккаунт можно добавить с начального экрана.
- Поля смены установленного кода скрыты под кнопкой «Изменить код». Touch ID и автоблокировка остаются видимыми.
- При временном сетевом сбое проверки обновлений выполняется один повтор; вместо «fetch failed» отображается понятное сообщение.
- Описание обновления содержит только изменения предлагаемой версии, без истории выпусков.

## Maxweb 1.2.5

- Новый компактный экран блокировки с основным действием Touch ID и полем кода со встроенной кнопкой входа.
- Touch ID запрашивается автоматически при открытии экрана блокировки, если он включён и доступен. Отмена оставляет возможность входа кодом и ручного повтора.
- В интерфейсе «PIN» переименован в «код». Существующий код менять не нужно.

## Maxweb 1.2.4

- Колокольчик в боковой панели отключает системные уведомления отдельного аккаунта, включая звук баннеров.
- Доступен в развёрнутом и свёрнутом виде, сохраняет выбор после перезапуска и закрывает уже показанные баннеры аккаунта.

## Maxweb 1.2.3

- В настройках внешнего вида добавлен масштаб внутреннего MAX в процентах: от 50 до 200% и кнопка сброса к 100%.
- Масштаб применяется ко всем аккаунтам без перезагрузки, сохраняется при перезапуске и повторной загрузке MAX.
- Команды ⌘+, ⌘− и ⌘0 меняют только содержимое MAX и синхронизируются с полем в настройках.
- Панель аккаунтов и настройки приложения сохраняют масштаб 100%.

- В свёрнутой панели убран отдельный логотип, оставлена кнопка раскрытия с векторной иконкой и понятным направлением стрелки.

## Maxweb 1.2.0

- Источник обновлений перенесён в effermount/Maxweb; сохранённый адрес прежнего репозитория заменяется автоматически.

- Новая геометрическая иконка M для приложения и строки меню.
- Боковая панель сворачивается до иконок аккаунтов и запоминает состояние (⌘⇧S).
- Название собственного профиля MAX подставляется автоматически; локальное редактирование и возврат к имени MAX доступны через карандаш.
- Уведомления страницы MAX проходят через нативный мост: настройки аккаунта, отправителя/чата, текста и звука, пример баннера и переход в нужный аккаунт.
- PIN 4–8 цифр, Touch ID на поддерживаемых Mac, ручная блокировка ⌘L, автоблокировка по бездействию, при сне и блокировке экрана.
- При блокировке скрываются аккаунты, настройки и личные данные в баннерах; клик по уведомлению открывает чат после разблокировки.
- Проверочная запись PIN защищена scrypt и Keychain, повторные ошибки ограничены задержкой.

## Maxweb 1.1.1

- Исправлена загрузка описаний выпусков через перенаправления GitHub Releases. Используется отдельный HTTP-стек без cookies MAX.
- Сохранены все функции версии 1.1.0: несколько аккаунтов, авторизации, фоновые уведомления и прокрутка к отправленному сообщению.

## Maxweb 1.1.0

- Несколько аккаунтов MAX в одном окне: боковая панель, названия аккаунтов и быстрые клавиши ⌘1–9.
- Изолированные авторизации. Вход основного аккаунта из версии 1.0 сохраняется автоматически.
- Неактивные аккаунты продолжают работать в фоне. Клик по уведомлению открывает соответствующий аккаунт.
- Счётчики непрочитанных сообщений для отдельных аккаунтов и общий счётчик в Dock.
- После отправки сообщения переписка автоматически прокручивается вниз. Входящие сообщения не мешают чтению истории; прокрутка вручную отменяет следование за отправленным сообщением.
- Обновления внутри приложения через публичные GitHub Releases: проверка, скачивание, проверка подписи и установка с перезапуском.
- Подписанные описания выпусков Ed25519 и проверка SHA-256 загруженного файла. При ошибке проверки приложение не заменяется.
