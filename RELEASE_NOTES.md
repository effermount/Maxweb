# Обла 1.1.0

Новая точка отсчёта — 26 ноября 2026 года.

- MAX, Telegram, WhatsApp и VK в одном приложении для macOS и Windows.
- Несколько аккаунтов с отдельными сессиями, сворачиваемая панель и порядок профилей перетаскиванием.
- Системные уведомления с настройкой содержимого баннера и отключением отдельных аккаунтов.
- Светлая, тёмная и системная темы; масштаб содержимого мессенджеров от 50 до 200%.
- Код, автоблокировка и Touch ID на поддерживаемых Mac.
- Подписанные обновления из приложения с сохранением аккаунтов для обеих платформ.

Для перехода со старой нумерации установите 1.1.0 вручную один раз поверх прежнего приложения. Пользовательский профиль сохраняется; следующие обновления снова будут приходить из приложения.
