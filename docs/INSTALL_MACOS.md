# Установка «Обла» на Mac — бесплатно

Для установки не нужны платная подписка, аккаунт разработчика Apple или команды в терминале. Сборка подходит для Intel и Apple Silicon, включая M1, начиная с macOS 13.

## 1. Скачайте и установите приложение

1. Откройте [последний выпуск «Обла» на GitHub](https://github.com/effermount/Obla/releases/latest).
2. В списке **Assets** скачайте файл `Obla-…-universal.dmg`.
3. Откройте скачанный DMG.
4. Перетащите значок «Обла» в папку **«Программы» / Applications**.
5. Откройте «Обла» из папки «Программы».

## 2. Разрешите первый запуск

Если появилось сообщение **«Apple не удалось подтвердить, что файл „Обла“ не содержит вредоносного ПО»**:

1. Нажмите **«Готово»**, чтобы закрыть предупреждение и оставить приложение на компьютере.
2. Откройте меню ** → Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите страницу вниз до раздела **«Безопасность»**.
4. Рядом с сообщением о заблокированном приложении «Обла» нажмите **«Всё равно открыть»**. Название кнопки может отличаться в зависимости от версии и языка macOS.
5. Подтвердите действие паролем пользователя Mac или Touch ID, если система попросит.
6. В следующем диалоге подтвердите **«Открыть»**.

macOS сохранит исключение для этого приложения. Дальше его можно открывать обычным двойным щелчком. Вы разрешаете запуск конкретного приложения; защита остальных приложений остаётся включённой.

Разрешайте запуск, только если скачали сборку из [официального репозитория effermount/Obla](https://github.com/effermount/Obla) и доверяете её источнику. Подробности — в [инструкции Apple по открытию приложений на Mac](https://support.apple.com/ru-ru/102445).

## Если кнопки «Всё равно открыть» нет

- Ещё раз попробуйте открыть «Обла» из папки «Программы», затем вернитесь в «Конфиденциальность и безопасность». Кнопка появляется после заблокированной попытки запуска.
- Убедитесь, что сообщение относится именно к «Обла».
- На рабочем или учебном Mac разрешение может быть ограничено администратором. В таком случае обратитесь к нему.
- Если система пишет **«приложение повреждено»** или сообщает об обнаруженном вредоносном ПО, это другое предупреждение. Скачайте свежий DMG из официального выпуска; если сообщение повторяется, [создайте issue](https://github.com/effermount/Obla/issues), указав версию macOS, версию «Обла» и точный текст ошибки.

## Почему появляется предупреждение

Текущие публичные сборки не подписаны сертификатом Developer ID и не прошли нотариализацию Apple. Поэтому macOS требует вручную подтвердить запуск приложения, загруженного из интернета. Само это сообщение не является результатом обнаружения конкретного вредоносного ПО и не подтверждает безопасность сборки.

Подпись канала обновлений «Обла» проверяет подлинность обновлений внутри клиента. Она не заменяет Developer ID и проверку Gatekeeper при первом запуске.
